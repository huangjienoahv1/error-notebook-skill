# 错误经验错题本

## 使用方式

- 本文件是公开仓库随附的空白模板，不保存个人错题数据。
- 安装后运行 `node scripts/init-private-notebook.mjs`，在用户目录初始化私有错题本。
- 检索、校验和复核脚本默认优先使用私有错题本；没有私有文件时才读取本模板。
- 可以通过环境变量 `CODEX_ERROR_NOTEBOOK_PATH` 指定其他私有数据路径。

## 记录规范

- 写入前先检查是否已有相同或相近规则；优先补充原规则，避免重复堆积同义内容。
- 每条经验必须包含生命周期字段、适用条件或错误特征、根因判断、正确处理动作，以及需要避免的错误做法。
- 生命周期状态只能是 `有效`、`待复核`、`已失效` 或 `已替代`。
- 复核周期按变化风险分为 `90天`、`180天` 和 `365天`：工具、API、框架和云服务使用 90 天；操作系统、构建和部署环境使用 180 天；Git、安全边界和稳定操作原则使用 365 天。
- `有效` 条目必须记录真实的最后验证日期、下次复核日期和可复查证据；日期使用 `YYYY-MM-DD`。
- 到期不等于错误；复核失败后标记为 `已失效` 或 `已替代`，并保留确认日期、证据和替代关系。
- 只记录已经通过日志、命令结果或实际验证确认的跨项目经验，不记录未经确认的猜测和项目业务约定。
- 严禁记录密码、Token、Cookie、私钥、完整连接串、个人隐私和生产业务数据。
