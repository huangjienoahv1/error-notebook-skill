# 记录格式与生命周期

仅在新增、更新、迁移或复核条目时读取。检索命中本身不是验证证据。

## 条目格式

在已有分类下使用三级标题；缺少合适分类时新增二级分类。每个字段只在围栏代码块外出现一次，冒号后的内容不能为空；代码块中的示例不作为字段。以下为结构说明，写入时替换为真实内容和日期，不直接复制示例文字：

```markdown
## 分类

### 可检索的具体标题

- 状态：有效
- 复核周期：90天
- 适用范围：明确的软件版本、操作系统、工具入口和触发边界。
- 最后验证：YYYY-MM-DD
- 下次复核：YYYY-MM-DD
- 验证证据：实际执行的命令、日志或代码位置，以及可观察结果。
- 替代条目：无
- 适用条件或错误特征：准确错误、环境和触发条件。
- 根因判断：经过证据确认的根本原因。
- 正确处理：已验证的处理动作和必要边界。
- 禁止做法：会掩盖问题、扩大风险或已证实无效的做法。
```

官方资料可以支持根因判断，但不能代替当前任务的修复验证。只记录脱敏后的必要证据，不复制完整日志或业务数据。

## 状态判定

| 情况 | 处理 |
| --- | --- |
| 在记录的适用范围内实际验证成功 | 标记为 `有效`，更新验证日期、证据和下次复核日期 |
| 仅命中条目，或当前环境不在适用范围内 | 保留原记录，不刷新日期，也不据此否定原经验 |
| 需要复核但受权限、网络等限制无法完成 | 保留已有验证证据；必要时标为 `待复核`，说明限制，不伪造新验证日期 |
| 证据证明原适用范围内的处理方式已不成立 | 标记为 `已失效`，记录确认日期和证据 |
| 已验证的新条目取代旧条目 | 标记为 `已替代`，使用 `分类 / 标题` 指向同一本中的替代条目 |

`已到期` 和 `字段异常` 是脚本计算的显示标签，不是可写入的状态。状态、日期或周期不合法时显示 `字段异常`，纳入复核扫描的待处理项；可用校验脚本定位原因。到期只表示需要复核，不表示经验错误。失效和替代条目保留历史，不直接删除；替代关系不得指向自身或形成循环。

## 日期与周期

下列周期是本错题本的约定，不是 Agent Skills 格式要求：

- 工具、API、框架和云服务：`90天`。
- 操作系统、构建和部署环境：`180天`。
- Git、安全边界和稳定操作原则：`365天`。

`有效` 条目必须有真实证据和 `YYYY-MM-DD` 日期；最后验证不能晚于今天，下次复核必须晚于最后验证且间隔不超过所选周期。可取“实际验证日期 + 周期天数”，不得把创建或阅读日期当作验证日期。有效条目的替代条目填写 `无`。

迁移前没有可靠日期或证据的存量条目使用 `待复核`，允许填写：

- 复核周期：`待首次复核时确定`。
- 最后验证：`未记录（迁移存量）`。
- 下次复核：`首次命中时`。
- 验证证据：`待复核后补充`。

这些值仅用于迁移存量，不能用来绕过新经验的写入门槛。`待复核` 条目一旦填写真实日期，同样检查未来验证日期、日期先后关系及已选周期上限。

`已失效` 和 `已替代` 的复核周期、下次复核填写 `不适用`，最后验证填写本次确认日期，并保留真实确认依据；没有替代项时填写 `无`。

## 写入后检查

对实际编辑的数据文件运行 `node scripts/validate-notebook.mjs`，自选文件时追加 `--notebook "数据文件绝对路径"`。脚本检查结构、日期与部分高风险凭据；校验通过不代表经验真实有效，仍需检查验证依据、适用边界、重复内容和敏感信息。

围栏代码块未闭合时，检索和复核扫描会报错并返回退出码 `2`，不会把无法解析的数据当作无匹配或无待处理项。
